**UAV AI Object Detection System**
A simulation-based UAV perception system integrating Deep Learning, Computer Vision, ROS 2, and ArduPilot SITL to detect and track objects in aerial video while synchronizing visual detections with UAV telemetry.
The system combines a custom-trained YOLO model, BoT-SORT multi-object tracking, and MAVLink telemetry integration to create an aerial object detection and monitoring pipeline.
